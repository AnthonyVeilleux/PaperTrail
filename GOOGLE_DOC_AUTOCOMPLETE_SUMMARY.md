Suggestions\nWhen you type `#` followed by letters, suggestions appear instantly with matching tags.\n\n### Partial Matching\nYou don't need the full tag name:\n- Type \"imp\" → See \"important\", \"implement\", \"imperial\"\n- Type \"res\" → See \"research\", \"researcher\"\n- Type \"pro\" → See \"project\", \"proposal\"\n\n### Smart Sorting\nMost frequently used tags appear first:\n- If \"research\" appears 12 times and \"researcher\" appears 5 times\n- \"research\" shows first in the dropdown\n\n### Usage Count Display\nEach suggestion shows how many times it's used:\n- `#research [12]` - Used 12 times\n- `#urgent [5]` - Used 5 times\n\n### One-Click Insertion\nJust click a suggestion and the full hashtag is inserted automatically.\n\n---\n\n## 🔧 How It Works\n\n```\n1. User types: \"#res\" in Google Doc\n   ↓\n2. System detects hashtag pattern\n   ↓\n3. getHashtagSuggestions(\"res\") called\n   ↓\n4. Searches all tags for matches\n   ↓\n5. Sorts by frequency (most used first)\n   ↓\n6. Returns top 5 results with metadata\n   ↓\n7. showHashtagAutocomplete() displays dropdown\n   ↓\n8. User clicks: #research\n   ↓\n9. insertHashtag(\"research\") called\n   ↓\n10. Partial \"#res\" replaced with \"#research\"\n    ↓\n11. Document updated instantly\n```\n\n---\n\n## 💡 Example Use Cases\n\n### Case 1: Research Documentation\n```\nTyping: \"This finding relates to my #res\"\nSuggestion: #research\nResult: \"This finding
