# ⚡ Autocomplete - Quick Reference Card

## 🎯 What Is It?

A smart search feature that suggests tags as you type in the search bar.

---

## 🚀 How to Use (30 Seconds)

### Step 1: Click Search Bar
```
🏷️ Paper Trail
[Search tags...] ← Click here
```

### Step 2: Type
```
[Search tags...]
imp ← Type "imp"
```

### Step 3: See Suggestions
```
[imp]
├─ #important [5]
├─ #imperial [2]
└─ #implement [8]
```

### Step 4: Select
**Mouse**: Click on a tag
**Keyboard**: Press ↓↑ then Enter

### Step 5: Results Filter
```
📁 My Research
   #important [5] ← Only showing matches
```

---

## ⌨️ Keyboard Shortcuts

| Key | What It Does |
|-----|--------------|
| ↓ | Move down |
| ↑ | Move up |
| Enter | Pick it |
| Escape | Close menu |

---

## 💡 Quick Tips

- Type "imp" to find "important"
- Use or skip the # symbol  
- Search is case-insensitive
- Numbers show how many times used
- Most used tags appear first

## ❓ FAQ

**Q: How do I close the suggestions?**
A: Press Escape or click outside the box

**Q: Can I use the keyboard only?**
A: Yes! ↓↑ to navigate, Enter to select

**Q: Why is the search case-insensitive?**
A: Easier typing - "IMPORTANT", "important", "Important" all work

**Q: What if no tags match?**
A: You'll see "No Tags Found" message

**Q: Does it filter the main list?**
A: Yes! Selection auto-filters what you see
