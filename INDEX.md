## ⚡ 60-Second Summary

### What Is It?
A smart search feature that suggests tags as you type.

### How Do I Use It?
1. Click the search bar
2. Type a tag name
3. Click/select from suggestions
4. Main panel filters automatically

### Keyboard Shortcuts?
- **↓** - Next suggestion
- **↑** - Previous suggestion
- **Enter** - Select
- **Escape** - Close

### Any Other Info?
See [AUTOCOMPLETE_CHEATSHEET.md](./AUTOCOMPLETE_CHEATSHEET.md) for quick facts!

## ❓ Common Questions

**Q: Where's the search bar?**
A: Top of the Tag Manager sidebar

**Q: How do I see suggestions?**
A: Just start typing in the search bar

**Q: Can I use keyboard only?**
A: Yes! Use ↑↓ arrows and Enter key

**Q: How do I close suggestions?**
A: Press Escape or click outside

**Q: Does it search all tags?**
A: Yes! Projects and global tags

**For more Q&A:** See [AUTOCOMPLETE_CHEATSHEET.md](./AUTOCOMPLETE_CHEATSHEET.md)
